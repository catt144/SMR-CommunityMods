# Relaunched Fix Pack: Opt-In Modules

**Opt-In Modules** is a set of optional modules for *Surviving Mars: Relaunched*.
Every one of them is off, or at its vanilla base setting, until you turn it on in
**Options → Mod Options**. Nothing is patched on disk: the mod wraps the game's own
code while it runs. A module you leave off behaves like the unmodded game, except
that Train Hubs and Elevator Depots already built keep working.

## It works with or without the Relaunched Fix Pack

The two are separate downloads, and neither needs the other. Use the Opt-In
Modules on their own, the fix pack on its own, or both together.

## Installing and turning modules on

1. Add the mod, then enable it in the **Mod Manager**.
2. **Restart the game fully.** Turning the whole mod on or off in the Mod Manager
   only takes effect after a full restart, the same as every other mod; see
   [the restart rule](../install.md#installing-a-mod).
3. Go to **Options → Mod Options → Relaunched Fix Pack: Opt-In Modules** and turn
   on the modules you want.

Every module has its own switch on that page, and a switch takes effect as soon as
you press **Apply**, in both directions. The page works with a controller.

## Before you uninstall

1. Set both Drone dials back to base, press **Apply**, and save the game.
2. Demolish every Train Hub and both halves of every Elevator Depot, then save the
   game.
3. Then disable or remove the mod and restart the game fully.

Removing the mod while hubs or depots are still standing leaves buildings in your
save that the game no longer knows, and the game reports errors when that save
loads. With them demolished first, your stations go back to the game's own import
and export requests.

!!! note "Turning a module off is not the same as removing the mod"
    Turning a module off puts the game's own behaviour back; what the module
    already did stays done, and buildings already placed keep working. Removing the
    whole mod is different, because the Train Hub and the Elevator Depot exist only
    while it is installed. A Drone dial left off its base position keeps boosting
    your drones after the mod is gone, which is why the dials come first above.

## Console and gamepad players

**While any mod is enabled, the game does not unlock achievements on Xbox,
PlayStation or the Microsoft Store.** That is the game's own rule and it applies to
every mod, not just this one. Steam and other PC versions are not affected.

## Reporting a problem

The [report form](../report.md) already has an option for this mod: choose
**Relaunched Fix Pack: Opt-In Modules** under *Which mod is this about?* No account
is needed, and you can attach a save or a log privately.

## Game version

Built and tested on game version **1.1.1**.
