# Community mods for Surviving Mars: Relaunched

The **Relaunched Fix Pack** repairs defects in the game's own code rather than
rebalancing the game, and it is built to be added to a save you have already
played.

## The two things people ask before installing

### Is it safe for a save I have already played?

**Yes, including a long one.** The fix pack writes almost nothing into your
savegame, and what it writes means nothing to the game without it — apart from
one item that is deliberately left working, and is said so plainly. The full list
of what it stores is written out by name rather than summarised, on the
[installing page](install.md#what-it-puts-in-your-save).

It is built to be safe to add or remove at any time.

### Does it change how the game is balanced?

**The fix pack repairs bugs rather than rebalancing.** Almost every fix targets
something verified in the game's own code: the code says one thing, does another,
and the pack makes it do what it says.

One honest exception, marked in the fix list: **four fixes are judgment
calls** rather than plain repairs.

Preferences and features are not in the fix pack.

## What is in it

Bug fixes only. Nothing to configure, nothing to switch on — it works the moment
it loads.

Its repairs cover disasters and weather, colonists and domes, drones and
logistics, buildings and economy, trains, rockets and asteroids, and story
sequences. Several of them also repair damage already sitting in your save when
you load it.

## The other mod: Opt-In Modules

**Relaunched Fix Pack: Opt-In Modules** is a separate mod of optional modules
that change how the game plays, every one of them off, or at its base setting, until
you turn it on in Mod Options. It works with or without the fix pack, and the fix pack works without it.
It is not on the stores yet.
